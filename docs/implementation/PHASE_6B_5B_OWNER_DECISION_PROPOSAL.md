# Phase 6B.5B — Consolidated Owner Decision Register

**Status:** PRS-01 through PRS-10 are recommendations and every item is **PENDING OWNER APPROVAL**. This register supplements, and does not amend, `PHASE_6B_5A_OWNER_DECISION_ADDENDUM.md`. It does not authorize implementation.

## Already settled by Phase 6B.5A

Do not re-ask the owner to settle the six answer types, schema v1 grammar and strict key handling, required/optional/null/empty-value behavior, incomplete drafts, server validation against the exact pinned immutable revision, existing attempt states, submitted-response immutability, explicit submission, or the separation of submission from educational evaluation. Also settled: no automatic scoring/acceptance; preserve the existing model unless a demonstrated gap requires a separately approved physical-model change. These decisions remain governed by the 6B.5A addendum.
